## **❓ CRITICAL FAQ**

### **Q: Do I need to understand RSA encryption?**
**A:** No. Puppeteer handles it automatically. Read Part 1 of FINAL-RAG-AGENT-PROMPT.md to understand WHY, but you don't need to implement encryption yourself.

### **Q: Why can't I use fetch() or curl to get the laws?**
**A:** Because lob.gov.jo encrypts API responses with RSA. Only browsers have the decryption keys. Puppeteer runs a real browser, so it works. Manual encryption would be 100x more complex.

### **Q: Are the LegislationIDs correct?**
**A:** Yes. All 4 have been manually verified:
- 3392 (Labor Law 8/1996) ✓ Tested
- 536 (Civil Law 43/1976) ✓ Tested
- 3408 (Rental Law 11/1994) ✓ Tested
- 1028 (Commercial Law 12/1966) ✓ Tested

### **Q: What if the website changes?**
**A:** The Puppeteer scraper will adapt automatically because it runs real JavaScript. If selectors change, you may need to adjust them, but the RSA encryption handling is automatic.

### **Q: Can I skip the scheduler?**
**A:** Yes, but not recommended. Without it, laws won't auto-update. You'd need to manually run the scraper weekly.

### **Q: Do I need to implement AUTO-LEGISLATION-FINDER?**
**A:** No, it's optional. IDs are already verified. It's useful only if laws are added/removed in the future and you want auto-discovery.
