## **1.2 Technical Architecture: Angular SPA + RSA Encryption**

### **Discovery Timeline**

We analyzed the website through browser DevTools and discovered:

**Layer 1: Frontend Architecture**
```
lob.gov.jo uses Angular.js (old but still active)
  ↓
Single Page Application (SPA) - NOT a traditional multi-page site
  ↓
All page transitions use hash-based routing (#!/...)
  ↓
JavaScript renders content dynamically
  ↓
No server-side HTML rendering for legislation details
```

**Layer 2: API Endpoint**
```
All data requests go to: https://lob.gov.jo/OPSHandler/OPS.ashx
Method: POST
Response Type: application/json
```

**Layer 3: SECURITY - RSA Encryption** ⚠️
```
This is the critical discovery:

Browser sends:
  - Request data encrypted with RSA public key
  - Algorithm: RSA
  - Parameters:
    enc = [very long encrypted string]
    alg = rsa

Server sends back:
  - Response data encrypted with RSA
  - Browser decrypts using JavaScript
  - Renders HTML
```

## **1.3 Why This Matters**

### **What We Can't Do**
❌ Simple `fetch()` or `curl` won't work
❌ Cheerio HTML parsing won't work
❌ Basic HTTP clients won't work

**Why?** Because the API requires RSA encryption, and you need the browser's JavaScript cryptographic libraries to encrypt/decrypt.

### **What We Can Do**
✅ Use Puppeteer (real headless browser that handles JavaScript)
✅ Browser automatically encrypts requests
✅ Browser automatically decrypts responses
✅ We just extract the rendered data

## **1.4 The Network Flow (What Really Happens)**

When you search for "العمل" (labor) on lob.gov.jo:

```
Step 1: User clicks "Search" button
  ↓
Step 2: JavaScript event listener fires
  ↓
Step 3: Browser loads RSA public key from server
  ↓
Step 4: Browser encrypts search parameters with RSA
  Request becomes:
    {
      enc: "[1000+ character encrypted string]",
      alg: "rsa"
    }
  ↓
Step 5: Browser POSTs to https://lob.gov.jo/OPSHandler/OPS.ashx
  ↓
Step 6: Server receives encrypted request
  ↓
Step 7: Server decrypts with RSA private key
  ↓
Step 8: Server processes request (searches laws)
  ↓
Step 9: Server encrypts response with RSA
  ↓
Step 10: Server sends encrypted JSON back to browser
  ↓
Step 11: Browser receives encrypted response
  ↓
Step 12: Browser decrypts using JavaScript crypto
  ↓
Step 13: JavaScript parses JSON
  ↓
Step 14: Angular updates DOM with legislation data
  ↓
Step 15: User sees search results
```

# **PART 2: WHY PUPPETEER IS THE SOLUTION**

## **2.1 The Problem with Manual Encryption**

If we tried to implement RSA encryption manually:

```typescript
// This approach is WRONG for lob.gov.jo
import crypto from 'crypto';

const publicKeyPEM = '-----BEGIN PUBLIC KEY-----...';
const publicKey = crypto.createPublicKey(publicKeyPEM);

// Problem 1: We don't have the server's RSA public key
// Problem 2: The server changes the key periodically
// Problem 3: RSA encryption requires specific padding (PKCS#1, OAEP, etc.)
// Problem 4: lob.gov.jo might use custom key management
// Problem 5: Even if we get it right, server updates break everything
// Problem 6: Browser-side JavaScript uses specific crypto libraries
//           (TweetNaCl.js, libsodium, etc.) that may differ from Node.js
```

**Result:** Manual encryption would be fragile, error-prone, and break when lob.gov.jo updates their security.

---

## **2.2 Why Puppeteer Is Perfect**

Puppeteer runs a **real Chrome browser in headless mode**:

```
What Puppeteer Does:
  1. Launches actual Chrome browser
  2. Navigates to lob.gov.jo
  3. Browser loads HTML + JavaScript
  4. Browser loads RSA public key from server
  5. Browser runs Angular.js code
  6. Browser runs encryption libraries (automatically)
  7. Browser makes encrypted API call (automatically)
  8. Server responds with encrypted JSON
  9. Browser decrypts (automatically)
  10. Angular renders DOM with legislation data
  11. We extract rendered text using Puppeteer

Result: Perfect, reliable, future-proof solution
```

  /**
   * Fetch and store a single law
   * This is where the magic happens
   */
  private async fetchAndStoreLaw(lawMeta: LobLawMetadata): Promise<void> {
    if (!this.browser) throw new Error("Browser not initialized");

    let attempt = 0;
    let lastError: Error | null = null;

    while (attempt < this.retries) {
      try {
        attempt++;
        console.log(
          `[LobGovScraper]   Attempt ${attempt}/${this.retries}: Fetching...`

            console.warn(

            // Page might have loaded but selector not available
            // Try extracting anyway
          }

          // Extra wait for Angular to finish rendering

          await page.waitForTimeout(2000);

          console.log("[LobGovScraper]   → Extracting legislation text...");
          const lawText = await this.extractTextFromPage(page);

          if (!lawText || lawText.trim().length < 500) {
            throw new Error(

          console.log(
            `[LobGovScraper]   → Successfully extracted ${lawText.length} characters`
          );

          // Process the extracted law
          await this.processExtractedLaw(lawMeta, lawText);

          return; // Success - exit retry loop
        } finally {
          await page.close();
        }

          `[LobGovScraper]   ✗ Attempt ${attempt} failed: ${lastError.message}`
        );

          await new Promise((resolve) => setTimeout(resolve, waitTime));

      }

    throw lastError || new Error("Unknown error in fetchAndStoreLaw");
  }

  /**
   * Extract text from the rendered page
   * Uses multiple selectors to ensure we get content
   */
  private async extractTextFromPage(page: Page): Promise<string> {
    const text = await page.evaluate(() => {
      // List of selectors to try, in order of preference
      const selectors = [
        ".legislation-content",
        ".law-content",
        ".law-text",
        "main",
        "article",
        '[role="main"]',
        ".container main",
        ".page-content",
        "#content",
        "body",
      ];

      // Try each selector until we find content
      for (const selector of selectors) {
        const element = document.querySelector(selector);
        if (element) {
          const content = element.textContent;
          if (content && content.trim().length > 500) {
            console.log(`Found content via selector: ${selector}`);
            return content.trim();
          }
        }
      }

      // Fallback: return body text
      const bodyText = document.body.textContent;
      return bodyText ? bodyText.trim() : "";
    });

    // Clean up whitespace
    const cleanedText = text
      .replace(/\s+/g, " ") // Multiple spaces to single space
      .replace(/[\n\r]+/g, "\n") // Normalize line breaks
      .trim();

    return cleanedText;
  }

  /**
   * Store extracted law in database
   * Check for changes if law already exists
   */
  private async processExtractedLaw(
    lawMeta: LobLawMetadata,
    newText: string
  ): Promise<void> {
    const lawId = `${lawMeta.legislationNumber}/${lawMeta.legislationYear}`;

    // Check if law already exists
    const existingLaw = await db
      .select()
      .from(laws)
      .where(eq(laws.lawId, lawId))
      .limit(1);

    if (existingLaw.length === 0) {
      // NEW LAW: Insert it
      console.log(`[LobGovScraper]   → NEW law detected, inserting...`);
      const articleCount = this.countArticles(newText);

      await db.insert(laws).values({
        lawId,
        arabicName: lawMeta.arabicName,
        englishName: lawMeta.englishName,
        year: String(lawMeta.legislationYear),
        fullText: newText,
        articleCount: articleCount,
        lastUpdated: new Date(),
        lobGovUrl: lawMeta.lobGovUrl,
        isActive: lawMeta.status === "active",
      });

      console.log(
        `[LobGovScraper]   ✓ Inserted: ${articleCount} articles found`
      );
    } else {
      // EXISTING LAW: Check if changed
      const oldText = existingLaw[0].fullText;

      if (newText === oldText) {
        console.log(`[LobGovScraper]   → No changes detected`);
        return;
      }

      // LAW CHANGED: Detect specific changes
      console.log(`[LobGovScraper]   → CHANGES DETECTED, analyzing...`);
      await this.recordLawChanges(lawId, oldText, newText);

      // Update the law in database
      await db
        .update(laws)
        .set({
          fullText: newText,
          lastUpdated: new Date(),
          articleCount: this.countArticles(newText),
        })
        .where(eq(laws.lawId, lawId));

      console.log(`[LobGovScraper]   ✓ Updated with changes`);
    }
  }

  /**
   * Count articles in law
   * Format: "المادة N: ..."
   */
  private countArticles(lawText: string): number {
    const articleRegex = /المادة\s+(\d+)\s*:/g;
    let count = 0;
    while (articleRegex.exec(lawText) !== null) {
      count++;
    }
    return count;
  }

  /**
   * Extract individual articles from law text
   */
  private extractArticles(lawText: string): Record<string, string> {
    const articleRegex = /المادة\s+(\d+)\s*:\s*(.+?)(?=المادة\s+\d+|$)/gs;
    const articles: Record<string, string> = {};

    let match;
    while ((match = articleRegex.exec(lawText)) !== null) {
      const articleNum = match[1];
      const articleText = match[2].trim();
      articles[articleNum] = articleText;
    }

    return articles;
  }

  /**
   * Detect what changed between old and new law text
   */
  private async recordLawChanges(
    lawId: string,
    oldText: string,
    newText: string
  ): Promise<void> {
    const oldArticles = this.extractArticles(oldText);
    const newArticles = this.extractArticles(newText);

    let changesDetected = 0;

    // Find which contract types are affected
    const affectedTypes = this.getAffectedContractTypes(lawId);

    // ADDED articles
    for (const [articleNum, newArticleText] of Object.entries(newArticles)) {
      if (!oldArticles[articleNum]) {
        console.log(
          `[LobGovScraper]     • Article ${articleNum}: ADDED`
        );
        await db.insert(lawChangelog).values({
          lawId,
          articleNumber: parseInt(articleNum),
          changeType: "added",
          newText: newArticleText,
          affectedContractTypes: affectedTypes,
          detectedAt: new Date(),
        });
        changesDetected++;
      }
    }

    // MODIFIED articles
    for (const [articleNum, oldArticleText] of Object.entries(oldArticles)) {
      const newArticleText = newArticles[articleNum];
      if (newArticleText && oldArticleText !== newArticleText) {
        console.log(
          `[LobGovScraper]     • Article ${articleNum}: MODIFIED`
        );
        await db.insert(lawChangelog).values({
          lawId,
          articleNumber: parseInt(articleNum),
          changeType: "modified",
          oldText: oldArticleText,
          newText: newArticleText,
          affectedContractTypes: affectedTypes,
          detectedAt: new Date(),
        });
        changesDetected++;
      }
    }

    // REMOVED articles
    for (const [articleNum] of Object.entries(oldArticles)) {
      if (!newArticles[articleNum]) {
        console.log(
          `[LobGovScraper]     • Article ${articleNum}: REMOVED`
        );
        await db.insert(lawChangelog).values({
          lawId,
          articleNumber: parseInt(articleNum),
          changeType: "removed",
          oldText: oldArticles[articleNum],
          affectedContractTypes: affectedTypes,
          detectedAt: new Date(),
        });
        changesDetected++;
      }
    }

    console.log(
      `[LobGovScraper]   Found ${changesDetected} article-level changes`
    );
  }

  /**
   * Map law ID to affected contract types
   */
  private getAffectedContractTypes(lawId: string): string[] {
    const mapping: Record<string, string[]> = {
      "8/1996": ["employment"],
      "43/1976": ["rental", "service", "nda", "supplier"],
      "11/1994": ["rental"],
      "12/1966": ["supplier"],
    };

    return mapping[lawId] || [];
  }
}

// Export singleton instance
export const lobGovScraper = new LobGovJoPuppeteerScraper();

## **5.3 Understanding the Code Flow**

When you run the scraper:

```
1. initialize()
   └─ Launch Chrome browser in headless mode
   
2. updateAllLaws()
   └─ Loop through each law in lawsToScrape
      └─ For each law:
         └─ fetchAndStoreLaw(lawMeta)
            ├─ Create new browser page
            ├─ Navigate to law URL (e.g., lob.gov.jo/...LegislationID=3392)
            │  └─ Browser automatically:
            │     ├─ Loads HTML + JavaScript
            │     ├─ Loads RSA public key
            │     ├─ Runs Angular.js
            │     ├─ Angular loads legislation data via encrypted API
            │     ├─ Browser decrypts response
            │     └─ Angular renders DOM
            ├─ Wait for page load
            ├─ Extract text from rendered DOM (NO decryption needed)
            ├─ Store in Neon database
            ├─ Check if law changed (if already existed)
            ├─ If changed, record specific article changes
            └─ Close page
            
3. shutdown()
   └─ Close Chrome browser
```

## **5.4 What Can Go Wrong (And How to Fix)**

### **Issue: "Content selector not found"**
```
Likely cause: Page structure different than expected
Fix: Open lob.gov.jo in browser, inspect HTML, find actual selectors
```

### **Issue: "Insufficient text extracted"**
```
Likely cause: Page didn't fully load, or wrong selector
Fix: Increase wait times, check internet connection, verify URL
```

### **Issue: "Browser not initialized"**
```
Likely cause: initialize() not called before updateAllLaws()
Fix: Always call initialize() first
```

### **Issue: "Database connection failed"**
```
Likely cause: DATABASE_URL not set or Neon not responding
Fix: Check DATABASE_URL in Replit secrets, verify Neon database is running
```

### **Issue: "legislationId not found" / 404 page**
```
Likely cause: LegislationId is incorrect or law doesn't exist
Fix: Manually verify the ID on lob.gov.jo, update in code
```
